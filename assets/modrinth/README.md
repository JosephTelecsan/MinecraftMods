# assets/modrinth

Icons and art references for Modrinth pages. Same general look across the set: Minecraft pixel art, diagonal grass on the top-left and netherrack on the bottom-right, simple center symbol, no text.

## Layout

- `team-chat/team-chat-icon.png`: icon currently used on Modrinth for Team Chat
- `team-chat/team-chat-variant-*`: other drafts / references from the same style

New icons for More Pearls, Pause Game, Entity Counter, and SpectatorPlus should follow that base. Full prompts and upload notes live in `docs/MODRINTH.md`.
